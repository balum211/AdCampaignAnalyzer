# 📣 Ad Campaign Performance Analyzer

A Streamlit dashboard that helps a marketer see **which campaigns and channels are delivering results**. It compares spend, clicks, conversions, revenue and ROI across **Facebook, Instagram, Pinterest and Twitter**.

Built for **The Gen Academy, Mastering Agentic AI, Week 1 (Path B: Data Analysis with Vibe Coding)**.

![stack](https://img.shields.io/badge/stack-Streamlit%20·%20pandas%20·%20Plotly-blue)

## Features

| View | What it shows |
|---|---|
| **📊 Overview** | 8 KPI cards with units: Spend ($), Revenue ($), Conversions (#), ROI (%), CTR (%), CPC ($), Cost per conversion ($), ROAS (x). A spend-vs-conversions trend on two axes (daily, weekly or monthly), spend and conversion share by channel, auto-generated insights, and an optional AI summary. |
| **⚖️ Platform Comparison** | Any metric by channel, a spend-vs-conversions bubble chart, an ROI heatmap (channel × goal or audience), and a full channel scorecard. |
| **🔎 Campaign Details** | A searchable, sortable campaign-level table with CSV download, plus a daily drill-down for any single campaign. |
| **📈 Time Series** | Any metric over time by day, week or month, optionally split by channel, goal or audience, with a 7-period rolling average and a month-over-month change table. |

**Global filters** (sidebar): date range, channel, audience and campaign goal, plus *Reset filters*. Every tab uses the same `apply_filters()` function, so the views always agree. An empty filter result shows a clear message instead of blank charts.

Correctness choices:
- Rates (CTR, CPC, CPA, ROAS, ROI) are computed **after** summing. They are never averaged from daily rates.
- Division by zero gives "–", never `inf`.
- Uploaded CSVs with common ad-platform headers (`Amount Spent`, `Platform`, `Results`, `$1,200.50`) are normalized automatically.

## Quick start

```bash
# Windows: double-click run.bat
# macOS/Linux:
./run.sh
# or manually:
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

The app opens at http://localhost:8501.

### Optional: AI summary
Run `pip install anthropic` (already in requirements.txt), then set `ANTHROPIC_API_KEY` as an environment variable or in `.streamlit/secrets.toml` (see `secrets.toml.example`). A **✨ Generate AI summary** button then appears on the Overview tab. Set `ANTHROPIC_MODEL` to change the model.

## Data

`data/ad_campaigns.csv` is a **synthetic** sample: 28 campaigns × daily rows, Jan–Jun 2026, 2,207 rows. It was generated by `scripts/generate_sample_data.py` with a fixed seed, so it is fully reproducible.

| Column | Required | Notes |
|---|---|---|
| `date` | ✅ | Any parseable date |
| `campaign_name` | ✅ | |
| `channel` | ✅ | Facebook / Instagram / Pinterest / Twitter (any values work) |
| `spend` | ✅ | USD; `$` and `,` are stripped |
| `clicks` | ✅ | |
| `conversions` | ✅ | |
| `campaign_id`, `audience`, `goal`, `impressions`, `revenue` | optional | Missing text columns become "Unspecified" |

You can upload your own CSV from the sidebar. Common header aliases are mapped automatically (see `COLUMN_ALIASES` in `src/analytics.py`).

## Metric definitions

| Metric | Formula | Unit |
|---|---|---|
| CTR | clicks ÷ impressions | % |
| CPC | spend ÷ clicks | $ |
| Conversion rate | conversions ÷ clicks | % |
| Cost per conversion (CPA) | spend ÷ conversions | $ |
| ROAS | revenue ÷ spend | x |
| ROI | (revenue − spend) ÷ spend | % |
